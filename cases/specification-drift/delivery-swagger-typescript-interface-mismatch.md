## Summary

A `gh-aw-sdlc` issue generated by a compatibility audit reports that a Delivery API schema in Swagger did not match the TypeScript interface implementation.

## Affected System or Context

Delivery API Swagger schema and TypeScript model.

## Human Intent

The Swagger contract intended to define the client-visible Delivery object.

## Machine Knowledge

The TypeScript interface had different required and optional fields.

## Observable Reality

The issue lists fields required by Swagger and fields present or missing in `delivery.ts`.

## Where the Divergence Occurred

- Human Intent vs Machine Knowledge: Contract and implementation described different shapes.
- Machine Knowledge vs Observable Reality: Generated or typed clients could disagree with actual responses.
- Human Intent vs Observable Reality: API consumers could rely on fields that implementation did not provide.

## Impact

Potential breaking change for clients, deserialization failures, and release risk.

## Detection Method

Scheduled compatibility audit.
