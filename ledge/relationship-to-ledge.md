# Relationship to Ledge

This repository was started by people interested in the same problem space as Ledge: the difficulty of keeping project knowledge aligned as software changes.

The repository is not a Ledge product, SDK, CLI, benchmark, or marketing site.

## Position

Knowledge Drift is the problem this repository studies.

Ledge is one project that may be motivated by this problem, but this repository should not assume that Ledge is the correct solution, the only solution, or the organizing frame for the evidence.

## How Ledge may be mentioned

Ledge may be mentioned when relevant to:

- Repository provenance.
- Motivation for studying Knowledge Drift.
- Related work.
- A clearly labeled example, if supported by evidence.

Mentions should be factual and limited.

## How Ledge should not be used

This repository should not:

- Promote Ledge as the answer to Knowledge Drift.
- Organize evidence around Ledge features.
- Compare vendors in a way that functions as marketing.
- Convert cases into sales claims.
- Treat disagreement with Ledge's approach as out of scope.

## Contributor guidance

Contributors do not need to know about Ledge to contribute.

When reviewing contributions, maintainers should evaluate whether the contribution improves the public evidence base for Knowledge Drift. The contribution should not be judged by whether it supports any particular product direction.

The healthiest version of this repository is useful to researchers, maintainers, AI tooling builders, and software teams regardless of whether they have any interest in Ledge.
